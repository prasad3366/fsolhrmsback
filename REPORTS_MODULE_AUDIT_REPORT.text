7. REPORTS APIS
---------------

GET /api/reports/summary

Authentication:
- JWT required.
- RolesGuard required.

Allowed roles:
- SUPER_ADMIN
- CEO
- HR
- FINANCE_MANAGER
- IT_MANAGER
- SALES_MANAGER

The redundant Super_admin variant is normalized by RolesGuard.

Database operations:
- Count all employees.
- Count active employees.
- Count today's PRESENT/LATE attendance.
- Count open job postings.
- Count active/upcoming training programs.
- Count all training enrollments.
- Count completed training enrollments.
- Load all employees to build department counts.

Response:
{
  totalEmployees,
  activeEmployees,
  todayAttendancePercentage,
  trainingCompletionRate,
  activeDepartments,
  activeJobPostings,
  activeTrainingPrograms,
  departmentDistribution
}

GET /api/reports/export/employees

Authentication:
- JWT required.
- RolesGuard required.
- Same organization-wide role allowlist.

Parameters: none.

Query:
- Active employees only.
- Selects id, empCode, firstName, lastName, department, designation,
  dateOfJoining, employmentType.
- Orders by department, last name, first name.

Response:
Array of employee objects.

The route is named export, but the backend returns JSON rather than CSV.

GET /api/reports/export/attendance

Authentication:
- JWT required.
- RolesGuard required.
- Same organization-wide role allowlist.

Parameters:
- Optional startDate string.
- Optional endDate string.

Query:
- Reads AttendanceRecord.
- Joins through User.employee.
- Includes active employees only.
- Loads all matching records.
- Aggregates in application memory by employee.

Response:
Array of:
{
  employeeId,
  empCode,
  employeeName,
  department,
  totalPresentDays,
  totalAbsentDays,
  lateArrivals
}

GET /api/reports/export/training

Authentication:
- JWT required.
- RolesGuard required.
- Same organization-wide role allowlist.

Parameters: none.

Query:
- Loads every training program.
- Includes enrollment counts.
- Loads enrollment statuses for every program.

Response:
Array of:
{
  id,
  title,
  department,
  trainer,
  status,
  startDate,
  endDate,
  totalEnrollments,
  completedEnrollments,
  completionRate
}

8. EXISTING BUSINESS CALCULATIONS
---------------------------------
Executive summary:

Attendance percentage:
(todayPresent / totalEmployees) * 100

The result is rounded to a whole percentage. The denominator is all employees,
not active employees or employees expected to work that day.

Training completion:
(completedEnrollments / totalEnrollments) * 100

The result is rounded to a whole percentage.

Department count:
- Loads all employees.
- Groups by department in memory.
- Counts unique non-empty departments.
- Includes inactive employees.

Attendance export:
- PRESENT and LATE count as present.
- ABSENT counts as absent.
- HALF_DAY is ignored.
- Leave is not counted.
- Late is counted when status is LATE or clockIn is later than a hard-coded
  09:00 local cutoff.

Training export:
completionRate = completedEnrollments / totalEnrollments * 100

The result is rounded to two decimal places.

Frontend calculations:
- Adds percent signs to summary values.
- Applies fallback values of 0.
- Converts returned arrays to CSV.
- Generates filenames using the current UTC date.
